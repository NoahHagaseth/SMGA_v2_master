# SMGA_v2_master
Code and scripts used for creation of metagenome assembled genomes (MAGs) and visualization for the SMGA_v2 master thesis

All code used for data handling and visualization within R for the project is found within the "SMGA_v2.Rmd" file

Codes to plot NanoPlot comparison and mucin degradation heatmap in parse_mucin_degradation_DRAM_forRstudio.R and plot_mucin_degradation_heatmap.Rstudio.R were provided by my supervisor Arturo Vera-Ponce De León.
